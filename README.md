# 面试资料站

一个单文件静态页，两个大模块：

| 模块 | 内容 | 卡数 |
|---|---|---|
| **速查** | 考前 30 分钟速扫 / 场景题 12 步 / 项目全链路表达 | 40 张 |
| **手册** | 面试问答手册全文（前置 + 九章 + 附录） | 79 题（另含前置 4 张、附录 4 张） |

点开卡片才看答案，支持关键词搜索、跨模块提示、字号切换，手机可用。

## 怎么用

直接打开 `index.html`，或访问 GitHub Pages 地址。

- 顶部两个按钮：**速查** / **手册**，可来回切
- 地址栏加 `#handbook` 可直接进入手册模式
- 搜索框输入关键词（如「九问」「时间粒度」），当前模块没有时会提示另一个模块有几条
- 「全展开 / 全收起」：打印或通读时用
- 「字号」：三档循环切换
- 「浅色 / 深色」：一键换主题，选择存在浏览器本地，下次打开保持

## 内容来源

- **速查**（40 张）来自 `D:/我的文档/桌面/通用焚诀/05-场景题与售前答题/` 三份 md
- **手册**（79 题）来自 `output/qa-20261103/stage3/AI应用开发岗面试问答手册-73题版-v6.docx`
  （手动修改版；文件名写 73，实际 79 题，页面按实际显示）

手册模块由脚本从 docx 只读提取，落盘为 `build/handbook_data.py`，**不修改 Word 原文件**。提取时做三项变换：

1. 个人姓名 / 学校 / 届别替换为 `【】`，页面不出现真实身份信息
2. 「九、工程基础补篇」→「八」，「八、收尾」→「九」
3. 题号随之互换：原文 `Q9.x` → `Q8.x`，原文 `Q8.x` → `Q9.x`

## 怎么改内容

内容不在 HTML 里手改，在 `build/` 下：

- `build/part0.py` — 速查：板块 0（速扫）
- `build/part1.py` — 速查：板块 1（场景题 12 步）
- `build/part2.py` — 速查：板块 2（项目表达）
- `build/extract_docx.py` — 从 docx 提取手册数据（改 Word 后重跑）
- `build/handbook_data.py` — 自动生成，勿手改
- `build/build.py` — 模板、样式、交互、双模块组装

改完重新生成：

```bash
python build/extract_docx.py   # 仅当 docx 变了
python build/build.py
```

会覆盖根目录的 `index.html`。

## 结构说明

- 速查标准卡四块：面试官原话 / 20 秒答法 / 展开讲 / 他可能追什么
- 两张特殊卡（需求访谈九问、七维打分器）用自定义结构：九问是嵌套折叠，打分器可点选并实时给结论
- 手册题卡五块：他在测什么 / 照着说 / 这是什么 / 他要追的话 / 红线（缺项自动省略）
- 配色全部走 CSS 变量：`:root` 是深色默认值，`body.light` 整包覆盖。**不要在任何组件里写死颜色**，否则浅色模式会漏色（白底白字）。少数字面色用 `--fg2`（正文灰）、`--strong`（加粗黑/白）、`--red2`（红线红）、`--purple2`、`--green2`、`--amber2`、`--okfg` 这些语义变量。

无外部依赖，不需要联网加载任何资源。
