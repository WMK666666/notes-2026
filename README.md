# 技术速查笔记

一个单文件静态页：场景题走位、项目表达、考前速扫。点开卡片才看答案，支持关键词搜索，手机可用。

## 怎么用

直接打开 `index.html`，或访问 GitHub Pages 地址。

- 顶部搜索框：输入关键词（如「九问」「时间粒度」），只剩相关内容
- 「全展开 / 全收起」：打印或通读时用
- 「字号」：三档循环切换
- 卡片标题带 `待你填` 的，是需要本人补事实的三张

## 怎么改内容

内容不在 HTML 里手改，在 `build/` 下：

- `build/part0.py` — 板块 0（速扫）
- `build/part1.py` — 板块 1（场景题 12 步）
- `build/part2.py` — 板块 2（项目表达）
- `build/build.py` — 模板、样式、交互

改完重新生成：

```bash
python build/build.py
```

会覆盖根目录的 `index.html`。

## 结构说明

每张标准卡固定四块：面试官原话 / 20 秒答法 / 展开讲 / 他可能追什么。
两张特殊卡（需求访谈九问、七维打分器）用自定义结构：九问是嵌套折叠，打分器可点选并实时给结论。

无外部依赖，不需要联网加载任何资源。
